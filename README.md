# Lexis Tools

Lexis Tools — это современный и мощный набор инструментов для администрирования игровых серверов (в первую очередь ориентированный на платформы GTA V / RAGE MP). Наше приложение создано для того, чтобы максимально упростить, автоматизировать и ускорить повседневные задачи администраторов.

## Основной функционал

*   **Игровой Оверлей (Биндер):** Удобный прозрачный внутриигровой интерфейс, позволяющий моментально выдавать наказания и отвечать на репорты без сворачивания игры.
*   **Умные Макросы и Бинды:** Возможность настройки горячих клавиш (включая боковые кнопки мыши) для выполнения цепочек действий и быстрой вставки текста.
*   **Быстрые ответы (Quick Replies):** Организованная библиотека часто используемых ответов, рассортированная по категориям, с возможностью копирования и вставки прямо в чат.
*   **База Правил и Редактор:** Удобный навигатор по правилам сервера с возможностью поиска, скрытия разделов и выдачи наказаний в один клик. Встроенный редактор позволяет настраивать базу правил под нужды вашего проекта.
*   **Голосовое управление (AI):** Инновационный функционал для выдачи наказаний и выполнения действий с помощью голосовых команд.
*   **Парсер форума:** Интегрированный инструмент для просмотра и обработки жалоб с форума прямо внутри приложения.
*   **Управление мероприятиями (Эвенты):** Модуль для контроля и проведения внутриигровых ивентов.
*   **Поддержка профилей:** Сохранение различных конфигураций настроек, биндов и ответов с возможностью мгновенного переключения между ними (идеально подходит для администрирования нескольких серверов).
*   **Интеграция Discord RPC:** Автоматическое отображение вашего статуса и текущей деятельности в профиле Discord.
