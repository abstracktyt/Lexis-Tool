# 🛠 Lexis Tools

**Твой набор админ-инструментов для сервера** — правила, профили, биндеры, онлайн-мониторинг и наказания в одном приложении.

</div>

---

## ⚙️ Возможности

- **Правила** — удобный редактор, парсер форума, главы со сворачиванием.
- **Профили** — отдельные наборы правил и биндов под разные ситуации.
- **Биндер** — макросы по горячим клавишам, готовые наборы по ролям.
- **Онлайн** — кто сейчас в голосовых каналах, роли с цветными градиентами.
- **Оверлей правил** — поверх игры: поиск, закрепление, компактный режим.
- **Оверлей онлайна** — компактный прозрачный список участников по нажатию клавиши.
- **Наказания** — выдача с подтверждением, звуком и системными уведомлениями.
- **Оформление** — настраиваемые акценты, баннеры/GIF в профиле, свой стиль.

## 📥 Установка

1. Скачай последний установщик (**`Lexis-Tools-Setup-*.exe`**) со страницы **Releases** этого репозитория.
2. Запусти установщик, выбери папку и нажми «Установить».
3. Открой **Lexis Tools**, войди через **Discord** — и приложение готово.

> Приложение автоматически проверяет обновления и предлагает установить новую версию.

## 🎮 Использование

- Оверлей правил — клавиша по умолчанию **Alt+O**.
- Оверлей эвентов — **Alt+E**.
- Оверлей онлайна — **Alt+U**.
- Все горячие клавиши можно сменить в «Настройки → Горячие Клавиши».
